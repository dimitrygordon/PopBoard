# Beyond 3D VR storybook audio

Placeholder narration for pages `s1` to `s27`. The words are the storyboard captions in `public/fourth-dimension/vr/vr4d-book.js`. The voice is eSpeak NG (`en-us`), generated by `tools/fourth-dimension/render-vr-narration.mjs`. It is a stand-in until the teacher records the final read.

## Drop in the teacher's recordings

Replace the files by the same filename. Do not rename them.

| File | What it is |
|---|---|
| `s1.mp3` … `s27.mp3` | One clip per page, in order. `s1` is the cover, `s27` is the last card. |
| `s1.json` … `s27.json` | Word times for that clip: `{"words":[{"w","start","end"}],"duration"}`. `w` is the caption word, `start` and `end` are seconds. |
| `../manifest.json` | `{"vr4d":[1,2,…,27],"score":null}`. The player reads this file (same layout as the astronomy course). The list is the pages that have a clip. |

The player is the astronomy storybook narrator (`public/astro-course/ac-narrate.js`). It loads `s<N>.mp3` and highlights the matching word from `s<N>.json`. Captions still show, in full, if the sound is muted or a clip is missing.

To regenerate the placeholder voice on a machine with eSpeak NG and ffmpeg:

```
node tools/fourth-dimension/render-vr-narration.mjs
```

## Music

The score and the sound effects are synthesized in the browser (`vr4d-audio.js`). Nothing in this folder is required for the music.

To replace that score with a recording later, put the file in this folder and set `"score"` in `../manifest.json` to `vr4d/score.mp3`. The synth bed stops and the file loops in its place. Leave `"score": null` to keep the generated music. See `CREDITS.md` before adding a recorded track.
