Mr. Dimitry's notes: The Bohr model draws electrons on neat rings, which is a handy way to count shells. Real electrons are better described by quantum mechanics: each orbital (s, p, d, f) is a probability cloud showing where an electron is likely to be found, not a path it travels. Open any element and switch to QM orbitals to compare.
