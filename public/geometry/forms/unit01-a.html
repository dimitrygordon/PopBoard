Show every reason. A drawing is not evidence unless the problem gives it.

Original aligned items. Related scope: Jacobs Introduction and Chapters 1 and 2.

1.

On a construction sheet, two angles carry the same arc mark, but one is drawn much wider than the other. The sheet says matching arc marks are givens. What can you conclude? What should be fixed in the drawing?

2.

Someone claims f(n) = n² + n + 41 gives a prime for every whole number n. (A prime is a whole number greater than 1 whose only positive divisors are 1 and itself.) Work out f(40) exactly. Is the claim true?

3.

Lines l and m are different and cross at P. Q is on l but is not P. R is on m but is not P. Can the line through Q and R also go through P? Use only facts about which points lie on which lines.

4.

A made-up round planet has a circumference of 43,200 km. Two sites on one north-south circle are 900 km apart along the surface. If every degree of center angle matches the same arc length, what is the center angle? Name one assumption you would need to say this equals a shadow angle.

5.

A pen moves from A = (0, 0) to B = (4, 0) to C = (4, 3) to D = (0, 3) and stops. Is this path a polygon yet? Which single straight segment would finish a simple four-sided polygon?

6.

A circle centered at M and a circle centered at N have the same radius r. They share the point X. The distance MN is not given. Which of MX, NX and MN must equal r? Use only definitions.

7.

A made-up system has four points and only two lines: {A, B} and {C, D}. Its one rule is 'every point is on exactly one line.' Does the system follow the rule? Does the rule force all the points onto one line?

8.

A bin holds two compasses, C1 and C2, and one straightedge, S. All three are metal. For this bin, decide whether each claim is true: 'every compass is metal' and 'every metal object is a compass.' For a false claim, name an object that shows it.

9.

A 'triad' means three different points that are not all on one line. A proposed test is 'the record lists three point names.' Give two different records that pass the test but are not triads. Then write an exact 'if and only if' test.

10.

You are given a = b + c and b = d + e. Prove a = d + e + c. A classmate writes c = d + e instead. Which statement follows, and why?

11.

Use only these two rules: x < x is never true, and if x < y and y < z, then x < z. Prove that a < b and b < a can't both be true.

12.

A system has three assumptions. S: every marked point is on line l. T: point P is marked. U: P is not on l. Can all three be true together? Show that removing any one of them gets rid of this contradiction.
